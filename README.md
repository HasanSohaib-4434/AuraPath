# AuraPath

**Your path. Your pace.**

AuraPath is an AI-powered personalized learning platform that generates custom learning roadmaps, helps you study smarter with AI tools, and keeps you motivated with gamification and wellness features.

🌐 **Live Demo:** [https://aurapath.netlify.app](https://aurapath.netlify.app)

---

## ✨ Features

### 🗺️ AI Learning Roadmaps
- Enter any learning goal (e.g. Master React & TypeScript, System Design, UI/UX, Data Science)
- Choose flexible timelines: 2 weeks → 6 months
- Compare **Fast vs Deep** learning paths
- Multi-language support: English, Urdu, Hindi, Arabic, Spanish, French, German
- Optional exam/deadline setting

### 📚 Smart Study Tools
- **Upload PDFs** and chat with your study materials
- Ask questions, get summaries, explanations, and quizzes from your documents
- **Voice input** — talk to the AI instead of typing
- Related **YouTube videos** automatically suggested
- Built-in **Flashcards** with spaced repetition
- **Pomodoro Timer** for focused study sessions
- Daily study plan in the "Today" section

### 🧪 Practice & Assessment
- **Mock Interviews** powered by AI
- Quizzes on your learning material
- Confidence tracking (before vs after)

### 📈 Progress & Gamification
- XP points and Learner Levels
- Study Streak tracking
- Badges and achievements
- Progress percentage on active path
- Portfolio view
- Downloadable **AuraPath Certificate** on completion

### 🧠 Wellness Features
- "Feeling Low?" mode with mini-games:
  - **Breath Bloom** — guided box breathing
  - **Focus Match** — memory card game
  - **Zen Pop** — bubble popping focus game
- Local high scores and personal records

### 🗂️ Path Management
- My Paths (all saved roadmaps)
- Active Path
- Resources & Explore sections

## 🛠️ Tech Stack

- **Frontend:** React + Next.js
- **Animations:** Framer Motion
- **Hosting:** Netlify
- **AI Features:** Speech Recognition (Web Speech API), PDF Chat, Roadmap Generation, Mock Interviews
- **Other:** Progressive Web App (PWA) ready

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/aurapath.git

# Navigate to project
cd aurapath

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 How to Use

1. **Set your goal** — Type what you want to learn and choose a timeline
2. **Generate path** — AI creates a personalized roadmap
3. **Follow tasks** — Complete levels with videos, docs, and quizzes
4. **Study daily** — Use Today section + Pomodoro + Flashcards
5. **Chat with materials** — Upload PDFs and ask questions (or use voice)
6. **Track progress** — Earn XP, badges, and maintain your streak
7. **Get certified** — Download your certificate when you finish
